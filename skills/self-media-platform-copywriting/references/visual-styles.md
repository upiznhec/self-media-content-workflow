# Visual style library

Before making images, choose a style for the current task from this library. The library defines reusable style presets; the account's brand colors, watermark and past preferences always take priority over preset defaults.

## Recommend and choose

1. After the title is approved and before setting the visual anchor, pick 2 to 3 candidates from the table below by content type and platform. They must also fit the tone set in the brief: playful content needs playful candidates, not only tidy ones. When no preset fits the tone, adapt one or propose a style of your own, and say which you did. When the content is about real events or real people and the user works with real footage or photos, make at least one candidate from real images, such as stills from footage the user has, or photos of the event; in its sample, mark where each image goes if you do not have it yet. Say who holds the rights to those images and what the user needs in order to post them (for example, nothing if they are the user's own, a credit, or a paid licence, with the price if the seller shows one).
2. Show each candidate as a small sample, made with the user's own title or text (render it as an image, or as an HTML page you show the user), with a sentence on how to recognize it and why it fits, and point out the differences. A description in words alone is not enough. Only if nothing can be rendered in this environment, say so, describe the candidates in words, and point to the design brief option. When you show new or revised samples, save them under a new file name (for example `-v2`) instead of overwriting the earlier ones.
3. Each time you show style candidates, ask in the same message how the images will be made, and write out both options in full, equally visible, as A and B, each worded as the user would say it, so that it keeps its meaning when the user repeats it:
   - **A. Make the images here**, with the tools available in this environment.
   - **B. Give me a design brief** to take to another AI image tool or design app.

   Do not shorten or leave out the second option. Wait for the user to choose a style (or describe their own) and one of the two options; if the reply could mean either option, ask which one. If the account profile already has a stable style preference, use it by default and say so, without recommending again.
4. Write the chosen style into the visual anchor section of the task card. One image set uses only one style, with the same palette and text style throughout.
5. The palettes in the presets are examples and can be swapped wholesale for the account's brand colors. When an account watermark is needed, add the same watermark placeholder in a fixed position.

## When the user chooses the design brief

Do not make the images. Write a design brief that the user can paste or upload into another AI image tool or design app, save it in the task folder, and note in the task card that the images are made outside. The brief must make sense on its own and includes:

- What to make: each image, the platform it is for and its size.
- Who the images are for and what they should do.
- The chosen style and palette, or the account's brand colors, fonts and watermark.
- The exact text for every image, marked as final so the tool does not rewrite it.
- Layout notes for each platform, such as the areas that the platform's buttons cover.
- What the images must not contain: invented interfaces or numbers, and logos, people or products the user has no rights to.
- What is still missing, such as the user's handle or a product photo.

Leave out research notes, private details and anything the user has not agreed to share. When the user brings the images back, check them against the brief with the checks at the end of this file.

## Quick routing

| Content type | First choice | Alternatives |
|---|---|---|
| Knowledge checklists, comparisons, processes, pitfalls to avoid | Cream infographic | Dossier cards, studio miniatures |
| Opinions, judgments, abstract concepts | Hand-drawn narrative metaphor | Minimal one-color line art |
| System relationships, loops, architecture | Studio miniatures | Minimal one-color line art, isometric tech scene |
| Illustrations inside in-depth articles | Isometric tech scene | Studio miniatures, hand-drawn narrative metaphor |
| Xiaohongshu covers for tutorials or tools | Dark neon | Cream infographic |
| Product recommendations, sponsored posts, an everyday persona | Photo collage with sticky notes | Dark neon |
| Long-article covers, magazine-style image cards | Typeset cards | Hand-drawn narrative metaphor |

## Style presets

### 1. Cream infographic

- How to recognize it: flat vector infographics on a cream background, black outlines on every element, no gradients and no shadows.
- Good for: structured knowledge such as frameworks, platform checklists, three-way comparisons, flowcharts and lists of mistakes.
- Where it goes: images in WeChat Official Account articles, X long posts and Xiaohongshu knowledge pages.
- Visual anchor example: off-white or cream background; a three-color system (one warm, one cool, one neutral, such as coral red, mint green and mustard yellow); simplified geometric icons; a large title plus a few keyword tags.
- Prompt skeleton: flat vector infographic, cream background, clean black outlines on all elements, no gradients no shadows, geometric simplified icons, generous white space, large prominent text.
- Use with care for: emotional storytelling, or content that needs realistic evidence.

### 2. Hand-drawn narrative metaphor

- How to recognize it: hand-drawn crayon or colored-pencil texture on a paper background; one central metaphor carries the whole claim, with small personified characters or a narrative scene if needed.
- Good for: opinions, industry judgments, abstract concepts, and covers where one metaphor should be understood at a glance.
- Where it goes: X images and covers, WeChat Official Account covers and concept images in articles.
- Visual anchor example: warm white paper background; three to four muted colors (such as orange, olive green and gray-green); text on the left and picture on the right, or a full-frame scene; a large bold black title with one word in the accent color.
- Prompt skeleton: hand-drawn editorial illustration, warm paper texture, crayon and colored-pencil shading, one central visual metaphor, muted palette with one warm accent, large headline area.
- Use with care for: content that needs a precise structure or many text labels.

### 3. Minimal one-color line art

- How to recognize it: thin line graphics in a single accent color on an off-white background, circled icons linked by curves, lots of empty space.
- Good for: loops, relationships, minimal system diagrams, and restrained, refined images for opinions.
- Where it goes: X, images in WeChat Official Account articles.
- Visual anchor example: off-white background; only one accent color (such as orange); line-art icons; a large centered title, with the graphic breathing below it.
- Prompt skeleton: minimal line art diagram, single accent color, thin consistent stroke, cream background, large centered headline, abundant negative space.
- Use with care for: image sets with dense information and many pages.

### 4. Dossier cards

- How to recognize it: a beige background with corner marks and halftone dots, rounded cards with thick black outlines, flat icons and arrows, with the feel of an engineering file.
- Good for: step-by-step processes, key-point lists and numbered breakdowns of methods.
- Where it goes: X images, Xiaohongshu knowledge pages.
- Visual anchor example: beige background; white cards with black outlines; one warning color for arrows and highlights (such as orange-red); a title font with a monospaced feel.
- Prompt skeleton: flat dossier-style card layout, beige background with corner marks, rounded cards with bold black outlines, flat icons, one accent color for arrows and highlights.
- Use with care for: emotional or everyday-life content.

### 5. Studio miniatures

- How to recognize it: concepts are made into physical miniature models placed in a photo studio, with an off-white background, black outlines and gray surfaces. The whole set uses only one saturated accent color, with short labels that each name one part.
- Good for: explaining concepts, system structures, loops and pipelines, nicer-looking charts, and abstract mechanisms that need to feel tangible.
- Where it goes: images in WeChat Official Account articles, X images, a central illustration that can be embedded in cards.
- Visual anchor example: off-white studio background; black outlines with light gray surfaces; one accent color marking arrows, nodes and key points (the same across the set); short horizontal labels placed in quiet areas.
- Prompt skeleton: clean 3D model-like illustration, off-white studio background, black ink outlines, subtle gray surfaces, exactly one vivid accent color, soft studio light, short horizontal labels in the post's language, generous safe margins.
- Use with care for: content that needs people's emotions or an everyday atmosphere. Keep labels short, a word or two each, and no more than five in a picture.

### 6. Isometric tech scene

- How to recognize it: miniature tech scenes in isometric view on a light background, with two clashing colors (such as blue and orange), making systems concrete as buildings, conveyor belts and robots.
- Good for: illustrations inside articles that tell big-picture stories, such as technical systems, industry change and before-and-after comparisons.
- Where it goes: images in WeChat Official Account articles and X long posts.
- Visual anchor example: light background; main color and contrast color on either side; isometric layout; a few large labels.
- Prompt skeleton: isometric tech scene illustration, light background, two contrasting color zones, miniature buildings and machines, clean editorial style, minimal large labels.
- Use with care for: checklist content that people need to scan quickly.

### 7. Dark neon

- How to recognize it: a dark background with neon glow effects, large glowing numbers or titles and saturated accent colors (orange, cyan), possibly with 3D characters or hand-drawn film elements.
- Good for: tool reviews, covers for tutorial round-ups, and Xiaohongshu first images that need a strong pull to click.
- Where it goes: Xiaohongshu covers, video covers.
- Visual anchor example: dark navy-black background; neon orange and cyan as two accents; an oversized number or title; three columns of key points at the bottom to close.
- Prompt skeleton: dark tech poster, deep navy background, neon glow accents, oversized glowing headline or number, high contrast, bottom info columns.
- Use with care for: images inside WeChat Official Account articles, and accounts with a restrained tone. Using it again and again on one account gets tiring; alternate it with light styles.

### 8. Photo collage with sticky notes

- How to recognize it: a collage on a white or off-white background, with a 3D character or a real photographed subject in the center, surrounded by macaron-colored sticky notes with washi tape, torn paper and kraft paper tags.
- Good for: product recommendations, sponsored posts, personal stories and everyday checklists.
- Where it goes: Xiaohongshu covers and inner pages.
- Visual anchor example: light, paper-textured background; sticky notes in several macaron colors; a centered subject; the title written on a large sticky note.
- Prompt skeleton: collage style cover, centered 3D character or real product photo, pastel sticky notes with washi tape, torn paper and kraft tag accents, soft clean background.
- Use with care for: serious technical content. When it is used for sponsored posts, keep the disclosure clear.

## Typeset cards (rendered as HTML)

Image-and-text cards do not have to come from an image model. When the environment can render HTML and take screenshots, the title, body and real photos can be composed with web layout, so the text is always sharp and under control:

- Magazine editorial: large serif titles, a paper-textured background, real photos or screenshots as the main evidence, and editorial metadata such as page numbers and section names. Good for long-article covers and slow-paced image posts.
- Swiss grid: a strict grid, large type in a light weight, one accent color and very little decoration. Good for tool and data content.

Both approaches follow the same rules: real images serve as evidence, not decoration, and one set keeps the same grid, fonts and palette. If the environment has a dedicated Skill installed for social cards or material illustrations (such as [guizang-social-card-skill](https://github.com/op7418/guizang-social-card-skill) or [guizang-material-illustration](https://github.com/op7418/guizang-material-illustration); note each one's license terms), the layout work can go to it first, with the presets in this library as style input. This repository does not contain any content from those external projects.

## Checks after generating images

- Style, palette and text style are consistent across the whole set, with nothing mixed in.
- Labels and text have no typos, nothing is cut off, and everything is readable at phone size.
- The cover text matches the approved title.
- No unexpected watermarks, unrelated logos or invented interfaces.
- When unsure, regenerate instead of delivering an image that only just works.
- After every change, look at the changed images again before saying they are fixed, and put all images of the set side by side (for example in one contact sheet) to catch a change that broke another image.
- Save each revision under a new file name (for example `-v2`, `-v3`) instead of overwriting the old file, so the user does not see an older copy that their viewer kept.
