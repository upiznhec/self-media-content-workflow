# Publishing pack

## Permission

Approving the final copy is not permission to publish or to write anywhere outside the content folder. Replies such as "looks fine", "leave it for now" or "I'll look later" do not count as permission. Never broadcast to several platforms at once.

## Manual publishing pack

The user publishes on every platform by hand. Address the pack to the user; do not write notes for an editor, a designer or anyone else the user has not mentioned. Deliver only what the chosen platforms need:

- The final copy.
- Covers and the order of assets.
- For video made from footage, the asset list: each shot the edit needs, marked as one the user has or one still missing.
- Tags, hashtags, a first comment, a collection or background music.
- A commercial partnership disclosure.

Record the link and time only after the user reports that the post is published; never assume it has been published.
